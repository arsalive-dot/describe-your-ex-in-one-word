A make.fun entry for the **Describe Your Ex in One Word** bounty: one word
that sums up an ex, written by `main.py` to `/output/entry.txt`.

The entry: **unsubscribed** — the ex as a subscription you finally opted out of.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic: two runs write byte-identical output.
